使用帮助

四步完成敏感数据扫描

1
选择目标目录

在左侧输入路径或点击文件夹按钮浏览选择要扫描的目录。

2
配置扫描参数

选择需要扫描的文件类型（如 .txt、.docx、.xlsx）和要检测的敏感数据策略（如身份证号、手机号、私钥等）。

3
开始扫描

点击"开始扫描"，等待进度完成。扫描过程中可随时点击"取消扫描"中止。

4
查看结果并导出

在"扫描结果"页按级别筛选、排序，点击"查看"查看匹配详情。切换到"统计概览"查看图表，在"导出报告"页下载 JSON 或 CSV 报告。

界面区域说明

左侧栏扫描配置区：目录选择、文件类型、检测策略、进度显示
扫描结果文件级分类列表，支持级别筛选、排序、分页，点击"查看"展开匹配详情
统计概览汇总卡片 + 级别分布环形图 + 类别分布条形图
导出报告下载完整扫描报告（JSON 适合程序处理，CSV 适合 Excel 查看）

数据分级标准

扫描结果按敏感程度分为 5 个等级，级别越高风险越大。

L1
公开 (Public)

未发现任何敏感数据

L2
内部 (Internal)

包含邮箱地址、IP 地址等一般性信息

L3
机密 (Confidential)

包含身份证号、手机号、银行卡号、统一社会信用代码等个人敏感信息

L4
秘密 (Secret)

同一文件中包含 3 项及以上 L3 级别敏感数据，存在批量泄露风险

L5
管控 (Restricted)

包含私钥文件、云服务密钥（AWS/GitHub 等）、高熵密钥等核心凭证

检测策略说明

共 10 种内置检测策略，可在左侧栏自由组合启用。

身份证号18 位中国公民身份证号码，通过 GB 11643-1999 Mod11-2 校验
手机号中国大陆手机号码（1xx-xxxxxxxxx 格式）
银行卡号13-19 位银行卡号，通过 Luhn/Mod-10 算法校验
邮箱地址标准电子邮箱格式
IP地址IPv4 地址格式（各段 0-255 校验）
社会信用代码18 位统一社会信用代码，通过 GB 32100-2015 Mod31 校验
AWS密钥AWS Access Key ID（AKIA 开头的 20 位字符串）
GitHub TokenGitHub Personal Access Token（ghp_ 开头）
私钥文件PEM 格式私钥块（-----BEGIN ... PRIVATE KEY-----）
高熵密钥password/secret/token 等键值对中的高随机性字符串（Shannon 熵 > 4.5）

常见问题

扫描会修改我的文件吗？
不会。DataSentinel 只读取文件内容进行正则匹配分析，不会写入或修改任何文件。
为什么有些敏感数据没被检测到？
可能原因：1) 对应的检测策略未勾选；2) 文件类型未纳入扫描范围（如 .pdf 当前不支持）；3) 内容格式不符合检测规则（如身份证号需通过校验位验证，而非简单的 18 位数字匹配）。
扫描结果中的值为什么被隐藏了？
匹配值在界面中自动脱敏显示（如 138****5678），防止敏感数据在屏幕上暴露。导出的 JSON/CSV 报告中同样使用脱敏值。
扫描大目录会很慢吗？
扫描使用多核并行处理，纯文本文件扫描速度很快。Office 文档（.docx/.xlsx/.pptx）需要解压和 XML 解析，相对较慢。单文件超过 50MB 会自动跳过。
数据留在本地吗？
是的。所有扫描和分析完全在本地完成，不联网、不上传任何数据。关闭程序后扫描结果即清除，只有手动导出的报告文件会保留在磁盘上。
报告中的 CSV 文件用 Excel 打开乱码怎么办？
导出的 CSV 已添加 UTF-8 BOM 标记，Excel 2016+ 可直接打开。旧版 Excel 请通过"数据 → 从文本/CSV 导入"并选择 UTF-8 编码。
